원문에 등장하는 AI·n8n 핵심 용어를 처음 배우는 사람도 바로 구분할 수 있도록 “정의 + 쉬운 해석 + 사용 장면”으로 정리한다.

1. AI 관련 용어

AI Agent

LLM이 요청을 해석하고 필요한 도구를 선택해 실제 작업까지 수행하는 구조다.

AI Chain

정해진 순서로 모델과 여러 구성요소를 호출하는 체인이다. n8n에서는 Agent와 달리 지속 메모리 활용에 차이가 있다.

Embedding

텍스트·이미지 등의 의미를 숫자 벡터로 바꾼 표현이다. 유사도 검색의 기반이 된다.

Groundedness

AI 답변이 제공된 근거 자료에 얼마나 충실한지를 나타내는 개념이다.

Reranking

검색된 후보 문서들을 질문과의 관련성에 따라 다시 정렬하는 기술이다.

Memory

대화나 이전 상태를 유지해 다음 요청에서도 맥락을 이어가도록 하는 기능이다.

RAG

LLM이 외부 문서를 검색한 뒤 그 정보를 근거로 답하도록 만드는 검색 증강 생성 방식이다.

AI Tool

검색, 계산, DB 조회, API 호출처럼 Agent가 필요할 때 선택할 수 있는 외부 기능이다.

Vector Store

Embedding 벡터를 저장하고 유사한 벡터를 빠르게 찾도록 설계된 저장소다.

LLM

대규모 데이터로 학습하여 자연어 이해·생성 작업을 수행하는 언어 모델이다.

LangChain

LLM, 도구, 메모리, 검색 등을 연결해 AI 애플리케이션을 만들기 위한 프레임워크다.

2. n8n 기본 용어

API

프로그램이 다른 서비스의 데이터나 기능을 호출할 수 있게 한 인터페이스다.

Canvas

노드를 배치하고 연결해 Workflow를 만드는 시각적 작업 공간이다.

Cluster Node

루트 노드와 여러 하위 노드가 하나의 기능 집합처럼 동작하는 구조다.

Credential

API Key, OAuth, 계정 비밀번호 등 외부 서비스 인증 정보를 관리하는 객체다.

Data Pinning

개발 중 특정 노드의 출력 데이터를 고정해 같은 샘플로 반복 테스트하는 기능이다.

Editor

Canvas, 설정 패널, Execution 등 Workflow 제작과 관리를 위한 전체 UI다.

Entitlement

특정 플랜 기능을 사용할 수 있도록 인스턴스에 부여되는 사용 권한 개념이다.

Evaluation

실행 결과를 태깅·비교하여 Workflow 품질 변화를 점검하는 기능이다.

Expression

이전 노드 데이터나 환경 값을 참조해 필드 값을 동적으로 계산하는 표현식이다.

Node

Trigger, 데이터 조회, 가공, 분기, 전송 등 하나의 기능을 수행하는 Workflow 구성 단위다.

Project

Workflow, 변수, Credential을 팀·업무 단위로 분리해 관리하는 공간이다.

Root Node

Cluster Node에서 주요 기능을 담당하는 중심 노드다.

Sub Node

Root Node에 연결되어 모델·메모리·도구 등 추가 기능을 제공하는 보조 노드다.

Template

미리 만들어진 Workflow 샘플이다. 가져온 뒤 Credential과 세부 값을 수정해 사용한다.

Trigger Node

시간, Webhook, 이벤트 등 Workflow 실행 시작 조건을 정의하는 노드다.

Workflow

하나의 업무 프로세스를 자동화하기 위해 여러 노드를 연결한 전체 실행 흐름이다.

3. 초보자가 특히 헷갈리는 용어 비교

비교차이
Agent vs ChainChain은 정해진 호출 순서, Agent는 상황에 따라 도구 선택과 행동을 결정하는 구조에 가깝다.
Embedding vs Vector StoreEmbedding은 숫자 표현, Vector Store는 그 숫자를 저장·검색하는 장소다.
Node vs WorkflowNode는 한 기능, Workflow는 여러 Node를 연결한 전체 업무다.
Root Node vs Sub NodeRoot는 중심 기능, Sub는 중심 기능을 보조·확장한다.
Credential vs APIAPI는 외부 기능을 호출하는 통로, Credential은 그 통로를 사용할 권한 정보다.

4. 짧은 확인 예제

Webhook(Trigger Node) ↓ OpenAI Chat Model(Root/Model) ├─ Memory(Sub Node) └─ HTTP Request Tool(Sub/Tool) ↓ Slack(Node) 전체 묶음 = Workflow

이 구조에서 사용자의 메시지가 들어오면 Trigger가 실행되고, Agent/Model이 Memory와 Tool을 활용한 뒤 결과를 Slack으로 보낸다고 이해하면 된다.
