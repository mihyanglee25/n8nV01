CHAPTER 01 · INTRODUCTION

n8n이란 무엇인가

n8n을 단순한 “앱 연결 도구”가 아니라 데이터와 업무 흐름을 시각적으로 설계하는 노코드·로우코드 자동화 플랫폼으로 이해한다.

1. 30초 핵심 요약

한 문장으로 이해하기
n8n은 Trigger → 처리 노드 → 결과 노드를 연결하여 사람이 반복하던 업무를 자동 실행하는 워크플로우 플랫폼이다.
  • 드래그 앤 드롭으로 서비스를 연결할 수 있다.
  • Docker 등을 이용해 직접 운영하는 셀프호스팅 구성이 가능하다.
  • JavaScript·Python을 활용해 노코드의 한계를 보완할 수 있다.
  • LLM, Tool, Memory, MCP를 결합해 AI Agent 흐름을 만들 수 있다.

2. n8n의 5대 핵심 강점

1. 시각적 캔버스

노드를 배치하고 연결선으로 이어 업무 흐름을 눈으로 확인할 수 있다.

2. 다양한 서비스 연동

Google, Slack, Notion, DB, 클라우드 서비스 등을 공식·커뮤니티 노드로 연결할 수 있다.

3. 데이터 주권

셀프호스팅을 선택하면 민감 데이터를 자신의 서버 안에서 처리하는 설계가 가능하다.

4. 로우코드 확장

기본 노드로 어려운 가공은 Code 노드와 표현식으로 확장할 수 있다.

5. AI Agent

LLM이 검색·DB·HTTP 요청 같은 도구를 선택해 실행하도록 워크플로우를 설계할 수 있다.

3. 반드시 알아야 할 5대 개념

개념 쉬운 설명 예
Workflow 자동화 전체 설계도 매일 뉴스 수집 후 Slack 전송
Node 한 가지 기능을 수행하는 블록 Webhook, HTTP Request, If
Connection 노드 사이에서 JSON 데이터가 이동하는 길 HTTP → If → Slack
Credential API Key·OAuth 등을 안전하게 보관하는 인증 정보 Google OAuth, OpenAI API Key
Execution 워크플로우를 한 번 실행한 기록 입력·출력·오류 로그 확인
Schedule Trigger → HTTP Request → If → Slack 시작 수집 판단 알림

4. 초보자 첫 실습: 알림 워크플로우

  1. 새 Workflow를 만든다.
  2. Manual Trigger를 추가한다.
  3. Edit Fields(Set) 노드에서 message = "n8n 첫 실행 성공" 값을 만든다.
  4. 다음 노드에서 출력 JSON을 확인한다.
  5. 성공하면 Manual Trigger를 Schedule Trigger로 바꾸어 자동 실행 구조를 이해한다.
